# Expedientes Académicos

Sistema de gestão de expedientes de estudantes (cartas e requerimentos): registo e digitalização na secretaria, encaminhamento pelas assistentes, pareceres com assinatura electrónica e decisão final com documento em PDF.

- Protótipo (página única): [`sistema-expedientes/index.html`](sistema-expedientes/index.html)
